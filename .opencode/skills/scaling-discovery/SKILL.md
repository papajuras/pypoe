# Skill: Scaling Discovery

Use this skill during build discovery to identify and pursue meaningful scaling opportunities.

## 1. Identify the scaling axis

A scaling axis is a variable **X** such that increasing X improves an important build output through an explicit game mechanic.

Think:

**increase X → mechanic uses/converts X → output improves**

Examples include scaling from:

* stats or resources;
* charges, stacks, or stages;
* number of items, jewels, corpses, allies, enemies, etc.;
* levels;
* explicit per-X or X-based conversions.

A generic bonus is not automatically a scaling axis.

For example, `20% more damage` is a multiplier, not a scaling axis. It may improve a build, but it does not tell us **what the build scales with**.

## 2. Validate the relationship

When a possible scaling relationship appears, identify:

* **X** — what increases;
* **mechanism** — how X affects something;
* **output** — what becomes better because of X.

Apply this test:

> If I increase X, does the relevant output improve because of X?

Prefer explicit KB/graph relationships over assumptions or general game knowledge.

## 3. Decide whether to explore it

A useful scaling discovery should provide a direction for further exploration.

When you find `X → output`, look for graph-supported ways to:

* increase or generate X;
* make the output more valuable;
* enable or sustain the interaction;
* connect the interaction to a coherent build.

Do not immediately build around every scaling-looking modifier. A single `X → output` relationship is a lead, not necessarily a build.

## 4. Keep the distinction clear

Separate these roles when reasoning:

* **scaling axis** — what the build scales with;
* **generator** — creates/increases X;
* **consumer/converter** — uses X;
* **enabler** — makes the interaction possible;
* **multiplier** — improves the resulting output;
* **defense** — keeps the build alive.

These can all be useful, but they are not interchangeable.

The objective during discovery is to find a **coherent chain centered on a real scaling axis**, not merely to accumulate strong modifiers.
