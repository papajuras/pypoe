# Skill: Discovery API Usage

For graph discovery and KB exploration, use:

`santa-maria/tools/phase6_api.py`

Use the existing API methods rather than inventing alternative queries, traversal logic, or direct database access.

When the task asks for a **random** node, seed, Unique, or starting point, **random means randomness generated by our API**.

Do not choose something manually and call it random.

Use the API's random-selection mechanism and record the returned result.

The LLM must not select, bias, or replace an API-randomized starting point based on what looks interesting.
